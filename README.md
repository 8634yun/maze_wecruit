# 🩸 살점의 미로

HTML 파일 하나로 동작하는 그로테스크 호러 미로 게임입니다. 라이브러리 없이 순수 HTML + CSS + JavaScript로 만들었고, 그래픽은 전부 캔버스에 직접 그립니다(이미지 파일 없음).

**▶ 바로 플레이: https://8634yun.github.io/maze_wecruit/**

로컬에서 즐기려면 `index.html`을 브라우저로 열기만 하면 됩니다.

## 조작법

| 입력 | 동작 |
|---|---|
| 방향키 / `WASD` | 이동 |
| 화면 하단 방향 패드 | 이동 (마우스·터치) |
| 스와이프 | 이동 (모바일) |

## 규칙

좌상단에서 시작해 우하단의 **봉인된 문**으로 빠져나가면 다음 층으로 내려갑니다. 문은 꿰매어져 있어서, **🦴 뼈열쇠를 전부 모아야** 열립니다.

### 주울 것

| | 효과 |
|---|---|
| 🦷 이빨 | +10 |
| 👁 안구 | +30 (당신을 계속 응시합니다) |
| 🫀 심장 | 생명 1 회복 (최대 6) |
| 🦴 뼈열쇠 | 전부 모으면 문의 봉인이 풀림 |

### 피할 것

- **🕳 바닥의 아가리** — 밟으면 심장 −1, 제물 −5. 한 번 씹은 아가리는 사라집니다. 아가리를 하나도 밟지 않고 모든 열쇠와 출구에 닿는 경로가 항상 보장됩니다.
- **추적자** — 눈이 여러 개 달린 덩어리. 너비 우선 탐색으로 최단 경로를 계산해 벽을 따라 쫓아옵니다. 닿으면 심장 −1. 물린 뒤에는 놈이 미로에서 가장 먼 칸으로 밀려나고 잠시 멈춥니다. 층에 들어선 직후에는 유예 시간 동안 눈을 감고 있습니다.

미로에는 **갈림길(루프)** 이 있어서 한 바퀴 돌아 놈을 따돌리거나 아가리를 우회할 수 있습니다. 등급이 높을수록 막다른 길이 늘어 도망칠 여지가 줄어듭니다.

심장이 0이 되면 미로에 삼켜집니다. 제물(점수)과 심장은 층을 넘어가도 이어지며, 탈출하면 50 + 시간 보너스(빠를수록 최대 100)를 받습니다.

## 제물 등급 (난이도)

상단 드롭다운에서 선택하며, 선택한 등급은 브라우저에 저장됩니다.

| 등급 | 심장 | 추적자 | 유예 | 미로 증가 | 아가리 | 갈림길 |
|---|---|---|---|---|---|---|
| 자비 | 5 | 950ms · 2층부터 1마리 | 3.5초 | +2칸 (최대 20) | 적음 | 막다른 길 없음 |
| 고통 | 3 | 620ms · 5층부터 2마리 | 2.5초 | +2칸 (최대 24) | 보통 | 많음 |
| 참혹 | 3 | 430ms · 3층부터 2마리 | 1.8초 | +3칸 (최대 26) | 많음 | 보통 |
| 지옥 | 2 | 300ms · 2마리 시작, 최대 4마리 | 1.2초 | +3칸 (최대 28) | 아주 많음 | 적음 |

수치를 바꾸고 싶다면 `index.html` 상단의 `LEVELS` 객체 한 곳만 수정하면 됩니다.

## 구현 메모

- **미로 생성** — 깊이 우선 탐색(DFS) 백트래킹으로 완전 미로를 만든 뒤, 막다른 길을 뚫고 벽을 추가로 허물어(braiding) 우회로를 만듭니다. 완전 미로는 두 칸 사이 경로가 하나뿐이라 추적자를 피할 수 없기 때문입니다.
- **아가리 배치 검증** — 함정 칸을 통과 불가로 두고 BFS를 돌려, 모든 열쇠와 출구에 안전하게 닿을 수 있을 때까지 길을 막는 함정을 걷어냅니다.
- **길찾기** — BFS를 핏자국 추적(힌트), 추적자 경로, 리스폰 지점(가장 먼 칸) 계산에 함께 사용합니다.
- **연출** — 캔버스 2D. 비네팅, 필름 그레인, 피격 시 화면 흔들림과 붉은 시야, 바닥에 남는 핏자국, 심장이 하나 남았을 때의 맥동, 제목 깜빡임까지 모두 코드로 그립니다.
- **핏자국 추적** — 남은 뼈열쇠가 있으면 가장 가까운 열쇠까지, 다 모았으면 문까지의 최단 경로를 점선으로 표시합니다.
