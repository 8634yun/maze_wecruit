# 🌀 미로 탈출 (Maze Escape)

HTML 파일 하나로 동작하는 캔버스 미로 게임입니다. 라이브러리 없이 순수 HTML + CSS + JavaScript로 만들었습니다.

**▶ 바로 플레이: https://8634yun.github.io/maze_wecruit/**

로컬에서 즐기려면 `index.html`을 브라우저로 열기만 하면 됩니다.

## 조작법

| 입력 | 동작 |
|---|---|
| 방향키 / `WASD` | 이동 |
| 화면 하단 방향 패드 | 이동 (마우스·터치) |
| 스와이프 | 이동 (모바일) |

## 게임 규칙

좌상단에서 출발해 우하단 출구로 탈출하면 클리어입니다. 단, **🔑 열쇠를 전부 모아야 출구 자물쇠가 풀립니다.**

### 아이템

| | 효과 |
|---|---|
| ⭐ 별 | +10점 |
| 💎 보석 | +30점 |
| 💗 하트 | 하트 1칸 회복 (최대 6칸) |
| 🔑 열쇠 | 전부 모으면 출구가 열림 |

### 위협

- **🔥 함정** — 밟으면 하트 −1, 점수 −5. 밟은 함정은 사라집니다.
- **👻 추격자** — 너비 우선 탐색으로 최단 경로를 계산해 벽을 따라 쫓아옵니다. 닿으면 하트 −1. 잡히면 추격자가 미로에서 가장 먼 칸으로 밀려나고 잠시 멈춥니다. 레벨 시작 직후에는 유예 시간 동안 잠들어 있습니다.

하트가 0이 되면 게임 오버입니다. 점수와 하트는 레벨이 넘어가도 이어지며, 클리어하면 50점 + 시간 보너스(빠를수록 최대 100점)를 받습니다.

## 난이도

상단 드롭다운에서 선택하며, 선택한 난이도는 브라우저에 저장됩니다.

| 난이도 | 하트 | 추격자 | 유예 시간 | 미로 증가 | 함정 |
|---|---|---|---|---|---|
| 🌱 쉬움 | 5 | 950ms · 레벨 2부터 1마리 | 3.5초 | +2칸 (최대 20) | 적음 |
| 🙂 보통 | 3 | 620ms · 레벨 5부터 2마리 | 2.5초 | +2칸 (최대 24) | 보통 |
| 🔥 어려움 | 3 | 430ms · 레벨 3부터 2마리 | 1.8초 | +3칸 (최대 26) | 많음 |
| 💀 악몽 | 2 | 300ms · 2마리 시작, 최대 4마리 | 1.2초 | +3칸 (최대 28) | 아주 많음 |

수치를 바꾸고 싶다면 `index.html` 상단의 `LEVELS` 객체 한 곳만 수정하면 됩니다.

## 구현 메모

- **미로 생성** — 깊이 우선 탐색(DFS) 백트래킹. 모든 칸이 연결된 완전 미로라 정답 경로가 항상 존재합니다.
- **길찾기** — 너비 우선 탐색(BFS)을 힌트 경로, 추격자 추적, 추격자 리스폰 지점(가장 먼 칸) 계산에 함께 사용합니다.
- **렌더링** — 캔버스 2D. 캐릭터·유령·아이템은 전부 도형으로 직접 그렸고 이미지 파일이 없습니다.
- **힌트** — 남은 열쇠가 있으면 가장 가까운 열쇠까지, 다 모았으면 출구까지의 최단 경로를 표시합니다.
